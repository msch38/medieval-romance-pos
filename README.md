# medieval-romance-pos

This repository contains the datasets including the references, source code, and related files used in this project. It provides all necessary components to reproduce the experiments and results presented in the paper.

## General information

- `code/`  
  Contains all source code used for data preprocessing, analysis, and running experiments. The code files serve as the base code for all experiments in the project. Please note that the dataset, model name, and file paths may need to be adapted to match the specific configuration or requirements of your environment.

- `model_output_prompting/`  
  Includes the JSON output generated by the model during prompting-based experiments.
